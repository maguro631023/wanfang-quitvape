## 這是什麼

一個提供一般衛教資訊與行為改變支持的工具，協助有意願停止使用電子煙的青少年維持戒除行為。

介入架構參考 Graham AL, et al. *A Vaping Cessation Text Message Program for Adolescent E-Cigarette Users: A Randomized Clinical Trial.* JAMA. 2024;332(9):713-721. doi:10.1001/jama.2024.11057

本程式為獨立實作，**非該試驗所使用之原始訊息庫**。

## 功能範圍

- 依使用者自訂戒菸日的每日衛教訊息（戒菸日前 6 週至後 8 週；未設定者為 4 週技巧建立軌道）
- 隨選因應技巧：渴望、情緒低落、壓力、動機、滑倒後
- 放鬆與因應技巧庫：15 項，分呼吸／身體／注意力／生理回饋四類
- 自我記錄與 30 天點盛行戒菸、重複點盛行戒菸之計算
- 本地通知排程（僅安裝版）
- 台灣戒菸與心理健康資源指引

**本程式不進行診斷、治療或個別化醫療建議，亦不量測或解讀任何生理訊號。** 完整界線見 [`INTENDED_USE.md`](INTENDED_USE.md)。

## 資料處理

所有使用者資料**僅儲存於裝置本機**，不傳輸至任何伺服器，不建立帳號，不蒐集可識別個人之資訊。移除程式即移除所有資料。

## 開發

程式本體是單一 HTML 檔，無建置流程。直接用瀏覽器開啟 `www/index.html` 即可開發，但**提醒通知只在安裝版運作**，瀏覽器中會靜默略過。

推送到 `main` 且變更觸及 `www/` 時，Actions 會自動部署。部署前有三道檢查：

1. 內嵌 JavaScript 語法檢查
2. `noindex` meta 仍存在
3. 無對外請求（`fetch` / `XMLHttpRequest` / `sendBeacon`）

第 3 項不只是技術檢查——`INTENDED_USE.md` 第 6 節向審查者承諾了資料不離開裝置。若日後需要加入任何對外傳輸，該聲明與 Play 的 Data safety 申報都必須同步修改。

Android 打包見 [`CAPACITOR_SETUP.md`](CAPACITOR_SETUP.md)。

## 維護注意

**網址寫死在兩個地方**：`www/index.html` 中 QR code 的 SVG 路徑資料，以及其下方的網址文字。若更換網域，兩者都必須重新產生——只改文字的話 QR 看起來正常但會指向舊網址，且不易察覺。
